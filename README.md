# Practica Dokploy - Administracion de Infraestructura de TI

Universidad del Quindio - Facultad de Ingenieria de Sistemas y Computacion.

- `src/index.js`: aplicacion Express.js (endpoints `/`, `/health`, `/info`, `/db`).
- `package.json`: dependencias (express, mysql2).
- `docker-compose.yml`: stack multi-servicio de la fase 5.
- Despliegue: Dokploy (Docker Swarm + Traefik), build con Nixpacks.
